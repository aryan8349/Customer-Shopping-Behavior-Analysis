# Customer Shopping Behavior Analysis

## Overview
End-to-end data analytics project analyzing customer shopping behavior to extract business insights. Covers data cleaning, exploratory analysis, SQL querying, and dashboard visualization.

---

## Dataset
- 3,900 records, 18 features  
- Includes customer demographics, purchase details, and behavioral data  
- Missing values handled during preprocessing  

---

## Tools & Technologies
- Python (Pandas, NumPy)  
- PostgreSQL  
- Power BI  
- Gamma  

---

## Workflow

### 1. Data Processing (Python)
- Loaded dataset using pandas  
- Performed initial exploration (`info()`, `describe()`)  
- Handled missing values  
- Standardized column names  
- Feature engineering (age groups, purchase frequency)  
- Exported cleaned data to PostgreSQL  

### 2. SQL Analysis (PostgreSQL)
- Revenue by gender  
- High-spending discount users  
- Top-rated products  
- Shipping type comparison  
- Customer segmentation  
- Revenue by age group  

### 3. Dashboard (Power BI)
- Built interactive dashboard with key KPIs  
- Visualized revenue, customer segments, and trends  

---

## Results
- Loyal customers dominate  
- Discounts do not always reduce spending  
- Top products drive consistent engagement  
- Younger age groups contribute more revenue
